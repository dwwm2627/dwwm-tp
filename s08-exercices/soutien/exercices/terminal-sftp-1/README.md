# Terminal : sftp, puis Bandit

Cet exercice est dans le cours de la semaine 4 : ce dossier ne fait
que vous y renvoyer. Votre formateur vous donne aussi, en séance,
une fiche des commandes Linux et un questionnaire sur Bandit.

1. **sftp** : semaine 4, mardi,
   [« Si le temps le permet — sftp, puis pourquoi chiffrer ? »](https://kevinbdx35.github.io/dwwm-2026-2027/semaines/s04-environnement/mardi.html#si-le-temps-le-permet-sftp-puis-pourquoi-chiffrer).
   **Réussi si** : `ls` montre `readme` dans votre dossier.
2. **Bandit** : reprenez au dernier code que vous avez atteint,
   en suivant la semaine 4, mercredi,
   [« TP — OverTheWire Bandit »](https://kevinbdx35.github.io/dwwm-2026-2027/semaines/s04-environnement/mercredi.html#apr%C3%A8s-midi-autonomie-tp-overthewire-bandit-terminal).
   **Réussi si** : vous avez noté le mot de passe de chaque étape
   franchie, jusqu'à bandit11 au moins.

Ne copiez rien dans `dwwm-tp` pour cet exercice : notez vos mots de
passe Bandit dans un fichier à vous, **jamais** dans un dépôt.
